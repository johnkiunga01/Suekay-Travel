# 🦁 Suekay Tours

A Kenyan safari tourism web app — evolving from a brochure-style site into a full tourism booking platform.

## About

Suekay Tours showcases and (eventually) books Kenyan safari experiences. The project is being built with a scalable architecture from the start so it can support future integrations — payments, availability calendars, itinerary building, and multi-vendor tour listings — without a rewrite.

## Status: 🚧 In active development

This repo is a work in progress. Current focus:

- [ ] Tour/package listing pages
